# Licensed knowledge import templates

Use one JSON record per entity type: `plants`, `diseases`, `pests`, `deficiencies`, `relationships`, `treatments`, `diagnostic-rules`, `references`, and `images`.

Every record requires `entity`, `sourceId`, `citation`, approved reviewer/scientific-review statuses, version, and import batch ID. Images additionally require approved rights metadata. Do not include CABI/Plantwise content or internet images unless the registry explicitly records compatible commercial rights.
