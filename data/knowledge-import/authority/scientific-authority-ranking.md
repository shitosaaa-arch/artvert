# Scientific authority ranking

1. Official national plant-protection/regulatory authority with a compatible reuse license — preferred for country/label-dependent management.
2. Official university or public research institution with documented compatible license — preferred for reviewed regional descriptions.
3. Intergovernmental source with an explicit compatible record-level license — useful only within that license scope.
4. GBIF Backbone Taxonomy (CC BY 4.0) — accepted-taxonomy baseline; not disease/treatment authority.
5. Kew POWO/WCVP — taxonomy cross-check, pending documented reuse permission.
6. Internal ArtVert catalog — authoritative solely for existing ArtVert product facts.

Sources with unclear, NC, ND, paywalled, restricted, or redistribution-prohibited terms are not import authorities.
