# طلب إذن صريح لإعادة استخدام المحتوى

الموضوع: طلب إذن لإعادة استخدام محتوى معرفي زراعي في تطبيق وموقع تجاريين مع الإسناد

السادة/ [صاحب الحقوق أو المؤسسة] المحترمون،

تُعد شركة آرت فيرت مصر قاعدة معرفة زراعية غير منشورة وقابلة للتتبع على مستوى كل معلومة. نرجو تأكيد الإذن الكتابي أو الترخيص الصريح لإعادة استخدام المواد المحددة التالية: [العنوان والرابط والإصدار/التاريخ والصفحات أو الأصول].

نرجو تأكيد ما إذا كان مسموحًا لنا: التخزين في قاعدة بيانات وملفات JSON؛ الاستخدام في تطبيق وموقع تجاريين؛ الاقتباس والتكييف والترجمة إلى العربية؛ إعادة التوزيع داخل خدمات التطبيق؛ واستخدام الجداول والرسوم والصور المذكورة تحديدًا.

يرجى بيان شروط الإسناد والاستشهاد، والترخيص، وشروط الاستخدام التجاري والتعديل وإعادة التوزيع، وأي استثناءات أو موافقة مطلوبة للصور أو الرسوم. كما نرجو تأكيد مدة الإذن [المدة] ونطاقه الجغرافي [النطاق].

لن ندعي تأييد مؤسستكم لنا، وسنحفظ الإسناد والتتبع، ولن ننشر أي سجل قبل اكتمال المراجعة العلمية واللغوية والحقوقية.
